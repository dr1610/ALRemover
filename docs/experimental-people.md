# 人物別編集（実験）

一人の切り抜きには通常の **ALRemover** タブを使ってください。人物別編集は追加のモデルを必要とし、接触する腕・手・髪の所属を誤ることがあります。

## 1枚の中の人物を分けて調整する

1. **ALRemover 人物別（実験）** タブへ元画像を読み込み、**自動で人物分け**を押す。
2. 色分けされた人物をクリックして選択する。自動検出の初期IDは左からA・B…、最大8人。
3. 名前、所属範囲の広げ縮め、不透明度、合成プレビューへの表示を調整し、**この人物の調整を反映**を押す。
4. **保存する人物**と**保存する種類**を選び、**選択した人物・画像を PNG 保存**を押す。

各PNGは元画像と同じサイズ・位置です。人物ごとのPNG・マスク、背景、未割当、選択した人物を除いた画像を保存できます。非表示は合成プレビューだけに作用し、保存する人物は別に選べます。不透明度は人物PNG・マスクにも反映します。

人物を見落とした場合は **新しい人物を追加** を選んで胴体をクリックします。**手動指定で始める**なら、最初から人物ごとにクリックして登録できます。
同じ人物の腕・手などは **この人物に含める**、他人の部分は **この人物から除外** で指定してください。指定点を使って人物の所属を再推定します。

接触した手や肩などの細部は **ブラシで所属を修正** で塗り分けられます。

- 人物色: A=青、B=オレンジ、C=紫、D=緑、E=ピンク、F=黄、G=水色、H=灰。
- 白: どの人物にも割り当てず、未割当に残す。
- 黒: 前景から取り除き、背景に戻す。
- **人物色で塗った所の抜け・半透明も復元する**: チェックすると、その色の人物へ割り当てると同時に前景マスクを復元する。

塗った後は **所属の塗り分けを反映** を押してください。人物や設定を切り替える前に反映が必要です。反映前の線は消しゴム、反映後の操作は **ひとつ戻す**（最大12操作）で取り消せます。
**未割当をこの人物へ** は未割当の前景全体を選択人物に渡すため、色分けを確認して使ってください。

**編集を保存・再開** から `.alrneo.zip` を保存すると、元画像・人物マスク・指定点・手動の所属・調整値をまとめて残せます。同じ画像の編集を再開するための形式です。
保存先は `Neo/outputs/ALRemover/日付/people/`。PNG保存時にはレイヤー一覧のJSONも保存します。

### 人物分けと輪郭の関係

BEN2などで全体の前景アルファを作り、GroundingDINOで人物候補、SAM2.1で各人物の所属を推定します。**SAMの確信度を髪の透明度に重ねて掛けません**。人物分けによる二重の輪郭削りを避ける構成です。
同じ画素は一人にだけ割り当てます。決められない前景は未割当に残し、人物と未割当のアルファの合計は全体の前景アルファと一致します（不透明度100%時）。
人物間の境界は所属の区切りです。元画像で二人の色が混ざった画素をそれぞれの色へ復元する処理は含みません。
自動判定は接触・重なり・デフォルメによって誤ることがあります。隠れた体や背景は補完しません。画像間で同じ人物を追跡する機能は対象外です。


RT-DETRはこの公開版に含まれません。検出枠をドラッグして編集する機能も未実装です。
